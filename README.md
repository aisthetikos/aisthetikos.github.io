### 2. Lamperti Vocal Exercises
Classical vocal training exercises extracted from the original Lamperti Daily Exercises sheet music using AI OCR technology. Features 18 exercises with varying difficulty levels and practice instructions.

### Key Features

- **Progressive Timing**: Start with short counts and gradually increase duration
- **Same Breath Volume**: Maintain consistent breath intake throughout the exercise
- **Gentle Audio Cues**: Chimes signal each phase transition
- **Visual Guidance**: Clear phase indicators and countdown timer
- **Customizable Settings**: Adjust starting count and maximum count
- **Responsive Design**: Works on desktop and mobile devices

## How to Use

1. Set your starting count (3-12) and maximum count
2. Click "Start Exercise" and listen for the gentle chimes
3. Follow the phases: **Inhale** → **Hold** → **Exhale**
4. The count increases by 1 each cycle automatically
5. Focus on maintaining the same breath volume throughout

## Exercise Principles

Based on the traditional Farinelli technique, this exercise emphasizes:

1. **Breath Control**: Learning to control air with the body, not the throat
2. **Progressive Difficulty**: Gradually extending timing without increasing breath volume
3. **Continuous Flow**: No breaks between cycles for sustained practice
4. **Body Awareness**: Developing sensitivity to breath mechanics
